# Lunari

Lunari is a constructed language created by Hiori in 2026. It is designed mainly for Japanese speakers who want to become comfortable with English-style SVO word order through a lighter grammar system.

## What this site includes

- A searchable Lunari / English / Japanese dictionary
- A structured grammar guide with draft rules clearly marked
- Five interactive practice questions
- Responsive navigation and light/dark themes
- Accessible keyboard focus, labels, and reduced-motion support

## Pages

- `index.html` — overview and quick dictionary search
- `search.html` — full trilingual dictionary
- `grammar.html` — grammar rules and examples
- `practice.html` — interactive quiz
- `about.html` — the idea and principles behind Lunari

## Run locally

Open `index.html` in a browser, or run `npm run build` to create a deployable copy in `dist/`.

## Language status

Lunari is still evolving. Rules that are not fully decided—especially negation and the relationship between the copula and progressive forms—are shown as drafts instead of being silently treated as final.
